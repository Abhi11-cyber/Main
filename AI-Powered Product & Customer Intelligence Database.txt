1. PROJECT OVERVIEW
================================================================================

The project is an AI-powered product and customer intelligence database.

Instead of creating a small "student database" or a simple CRUD database,
we are building a realistic e-commerce/product-intelligence system that
gradually introduces:

================================================================================
2. WHY ARE WE BUILDING THIS PROJECT?
================================================================================

The purpose is NOT simply to create an application.

The primary purpose is to use a realistic project as a learning environment
for DP-800.

A traditional database can answer questions such as:

"Show all laptops."

"Show all customers from Maharashtra."

"Show products costing less than 80000."

"Show customers who placed more than 5 orders."

An AI-enabled database can eventually handle more meaningful queries such as:

"Find a lightweight laptop suitable for programming with long battery life."

"Find products similar to this customer's interests."

"Find products whose descriptions and reviews semantically match this request."

This introduces AI concepts such as:

- Embeddings
- Vector representations
- Semantic search
- Hybrid search
- Retrieval
- RAG
- AI-generated responses

Therefore, the project combines:

DATABASE ENGINEERING
+
AI DATABASE CAPABILITIES
+
DEVELOPMENT
+
SECURITY
+
PERFORMANCE
+
SOURCE CONTROL
+
API DEVELOPMENT
